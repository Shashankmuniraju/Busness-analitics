# Data Cleaning Using Power Query

## Project 4

**Source basis:** Data Cleaning Using Power Query -- Dirty Café Sales
Data

## Purpose

Cleaning 10,000 café transactions, handling missing/UNKNOWN/ERROR
values, correcting data types, checking duplicates, and validating
numerical relationships.

## A --- Power BI setup

A valid `.pbix` file cannot be manufactured reliably outside Microsoft
Power BI Desktop. Instead, this folder contains the complete reusable
Power BI setup: data template, DAX measures, Power Query instructions
where applicable, and dashboard specification.

Open Power BI Desktop and: 1. Import the provided CSV/template or
connect to the actual source. 2. Apply the listed transformations. 3.
Add the supplied DAX measures. 4. Create the listed visuals. 5. Add the
recommended slicers/filters. 6. Save the finished project as `.pbix`.
